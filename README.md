# KD-Odoo

AI-KD is an AI Assistant module for Odoo.

## Features

- 🤖 AI Chat (OpenAI, Gemini, Claude, Groq)
- 💬 Conversation History
- 📂 Repository Access
- ⚙️ Configurable AI Providers
- 📝 Chat History Management

## Supported Odoo Versions

- Odoo 19.0

## Installation

1. Copy the module into your custom addons path.
2. Update the Apps list.
3. Install the **AI Chatbot** module.
4. Configure the AI provider from **Settings**.

## Configuration

- API Key
- AI Provider
- Git OAuth Client ID
- Git OAuth Client Secret
